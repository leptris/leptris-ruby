### Step 1: Create Error Header (30 min)

Create `lib/src/errors.h`:

```c
#ifndef LEPTRIS_ERRORS_H
#define LEPTRIS_ERRORS_H

#include <stddef.h>
#include <stdbool.h>

// Error codes (add more as needed)
typedef enum {
    LEPTRIS_ERROR_NONE = 0,
    
    // Parse errors (1xx)
    LEPTRIS_ERROR_PARSE_UNCLOSED_TAG = 100,
    LEPTRIS_ERROR_PARSE_INVALID_ATTR = 101,
    LEPTRIS_ERROR_PARSE_ENCODING = 102,
    LEPTRIS_ERROR_PARSE_NAMESPACE = 103,
    LEPTRIS_ERROR_PARSE_MALFORMED = 104,
    
    // XPath errors (2xx)
    LEPTRIS_ERROR_XPATH_SYNTAX = 200,
    LEPTRIS_ERROR_XPATH_FUNCTION = 201,
    LEPTRIS_ERROR_XPATH_TYPE_MISMATCH = 202,
    LEPTRIS_ERROR_XPATH_NAMESPACE = 203,
    LEPTRIS_ERROR_XPATH_UNKNOWN_AXIS = 204,
    
    // Evaluation errors (3xx)
    LEPTRIS_ERROR_EVAL_CONTEXT = 300,
    LEPTRIS_ERROR_EVAL_ARGUMENT = 301,
    LEPTRIS_ERROR_EVAL_OVERFLOW = 302,
    
    // Generic errors (9xx)
    LEPTRIS_ERROR_OUT_OF_MEMORY = 900,
    LEPTRIS_ERROR_INTERNAL = 999
} LeptrisErrorCode;

// Error context structure
typedef struct {
    LeptrisErrorCode code;
    char* message;              // Primary error message
    char* context_snippet;      // Code snippet around error (optional)
    int line;                   // Line number (1-based, 0 if N/A)
    int column;                 // Column number (1-based, 0 if N/A)
    size_t byte_offset;         // Byte offset in input (0 if N/A)
} LeptrisError;

// Error API
LeptrisError* leptris_error_create(LeptrisErrorCode code, const char* message);
LeptrisError* leptris_error_create_with_context(
    LeptrisErrorCode code,
    const char* message,
    const char* input,
    size_t byte_offset,
    int line,
    int column
);
void leptris_error_free(LeptrisError* error);
const char* leptris_error_get_message(LeptrisError* error);
const char* leptris_error_get_full_message(LeptrisError* error);

// Global error state (thread-local in future)
void leptris_error_set(LeptrisError* error);
LeptrisError* leptris_error_get(void);
void leptris_error_clear(void);
bool leptris_error_has_error(void);

#endif // LEPTRIS_ERRORS_H
```

## Architecture Principles (CRITICAL)

**MUST FOLLOW**:
1. **MECE** - Errors mutually exclusive, collectively exhaustive
2. **Object-Oriented** - Error objects, not static strings
3. **Separation of Concerns** - C errors, FFI bridge, Ruby exceptions separate
4. **No Code Guards** - Architectural solutions, not `#ifdef`
5. **Single Responsibility** - Each function does one thing
6. **Clean Memory** - ALL allocations must be freed

**File Size Limits**:
- Target: ≤700 lines per file
- Maximum: 800 lines per file
- Current plan: errors.c (400), errors.h (100) ✅

## Common Pitfalls to Avoid

1. **Don't** use static buffers for messages (memory leaks)
2. **Don't** forget to free error context snippets
3. **Don't** use `printf` for error messages (use allocation)
4. **Don't** hardcode error messages (use error codes + formatting)
5. **Don't** skip memory leak testing (valgrind is required)
